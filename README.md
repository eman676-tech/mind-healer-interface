# Health Acknowledge Mockup (20)

A professional, high-fidelity UI/UX website mockup for a medical AI platform named "Health Acknowledge". Modern split-screen layout with clean, fresh, and calm healthcare aesthetics. The left side features a minimal, welcoming Sign-In and Log-In panel with soft input fields for Name and Email. The right side showcases a fresh and inviting AI Chat Board interface with soft mint green and light teal message chat bubbles. The interface includes an active chat stream where a patient describes symptoms like a fever, and a helpful AI chatbot responds. Every AI message displays a clear, small amber medical disclaimer note at the bottom.
